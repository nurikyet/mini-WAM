# mini-WAM — эксперименты

Полный порядок запуска на сервере: [plan.md](plan.md).

Скрипт автоматически сохраняет stdout, stderr и ошибки в отдельный файл каждого
запуска в `logs/`. Одновременно вывод виден в терминале.

```bash
bash scripts/train_server.sh all

# Во второй SSH-сессии:
tail -F logs/all-latest.log
```

Для отдельной одношаговой серии: `bash scripts/train_server.sh one-step` и
`tail -F logs/one-step-latest.log`.

В логе видны текущая стадия, прогресс и ETA, loss, validation SR, сохранение и
восстановление checkpoints, ошибки с traceback и итоговый код завершения.
Долгие стадии дополнительно печатают периодические сообщения ожидания.
Подробнее о запуске в фоне и чтении логов — в [плане](plan.md#логи-и-наблюдение-за-запуском).
